# LAPORAN PRAKTIKUM JOBSHEET 02

**Topik:** Implementasi CSS3 Styling Dasar

---

## 1.1 Tujuan

1. Mengimplementasikan *Cascading Style Sheets* (CSS) eksternal pada struktur dokumen HTML.

---

## 1.2 Struktur Folder

```text
Jobsheet 2/
├── index.html
├── README.md
├── anggota/
│   ├── list.html
│   └── tambah.html
├── assets/
│   └── css/
│       └── style.css
└── buku/
    ├── list.html
    └── tambah.html
```

## 1.3 Ringkasan

1. Direktori assets/css/
    * Penambahan folder baru yang memuat file style.css untuk mengatur gaya visual (styling) seluruh halaman web secara terpusat.

2. Pembaruan Halaman HTML
    * File index.html beserta file list.html dan tambah.html pada folder anggota dan buku telah dihubungkan dengan external CSS (style.css) agar tampilan tabel, tombol, dan formulir lebih rapi.
